## Flagged: no image for "The 'Sea of Stars'" (bioluminescence)

Searched Wikimedia Commons, Pexels, and Unsplash. Commons returned no
results at all for Maldives bioluminescence. Pexels and Unsplash both
returned genuine bioluminescence photography, but every result was
verified to be from elsewhere — Newport Beach and La Jolla (California),
Jervis Bay (Australia), Sicily — none from the Maldives. Using one of
those would misrepresent a different location's phenomenon as Maldivian,
which fails the same "must depict the named place" bar as the Amber Fort
example in the brief. **This attraction ships with the honest photo-slot
placeholder rather than a mismatched photo.**

Also rejected: an initial "manta ray feeding" Commons result was
confirmed (via its description page) to be from Pearl and Hermes Atoll,
Hawaii — not the Maldives. Replaced with a verified Maldives-specific shot.
